# Changelog

## 1.0.0 (2026-11-16)

First release.

- Nine skills: `opportunity-discovery`, `market-research`, `business-planning`, `financial-modeling`, `fundraising`, `go-to-market`, `venture-scaling`, `founder-context`, `agent-operations`.
- Seven-layer context pack and `CLAUDE.md` template, in Arabic and English.
- Eighteen templates in Arabic and English, plus an assumptions file and an investor pipeline sheet.
- Four workflows and two frameworks, in Arabic and English.
- `context_lint.py`: thirteen rules for context packs.
- `build_model.py`: monthly financial model with summary, CSV and Excel output, nine checks, Arabic and English labels.
- Worked example (fictional company Mawja): context pack in both languages and a built model.
- Repository validator, asset sync, distribution builder, unit tests and CI.
