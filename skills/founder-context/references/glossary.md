## Writing conventions · قواعد الكتابة

- Write Arabic natively; do not mirror English sentence structure.
- Use Western digits (0-9) with Arabic text unless the user's documents use Arabic-Indic digits.
- Currency: write the amount then the currency name or code the user uses («450 ريالًا» or "SAR 450").
- Dates in files and tables use ISO format (2027-01-31) in both languages.
- Product names, code, file paths and commands stay in Latin script.
