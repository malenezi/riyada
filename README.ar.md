# ريادة · Riyada

**مهارات وملفات سياق وقوالب لرواد الأعمال الذين يبنون منشآتهم ويشغّلونها بوكلاء الذكاء الاصطناعي. بالعربية والإنجليزية، ومعها برامج تفحص المُخرَجات.**

[English](README.md) · [المهارات](#المهارات) · [حزمة السياق](#حزمة-السياق) · [القوالب](#القوالب) · [المسارات](#المسارات) · [الأطر](#الأطر) · [مثال تطبيقي](examples/mawja/)

حين يستطيع الوكلاء تنفيذ معظم الأعمال الوظيفية، ينتقل دور المؤسس من أداء العمل إلى تحديده وتزويده بسياقه وتحمّل مسؤولية نتيجته. وأمران يحسمان نجاح ذلك: ما يتقنه المؤسس، وما يُقال للوكلاء عن المنشأة. فالوكيل ذو النموذج القوي بلا سياق ينتج عملًا عامًّا، والوكيل ذو الصلاحيات الواسعة بلا حدود ينتج مخاطر.

يجمع «ريادة» الجانبين:

- **تسع [مهارات](https://agentskills.io)** تعلّم Claude مسارات عمل المؤسس الأساسية، من اختبار الفكرة إلى حوكمة الوكلاء في التشغيل.
- **حزمة سياق من سبع طبقات** تخبر أي وكيل من هي المنشأة، وما المهم، وما يجوز له وما لا يجوز، ومعها فاحص آلي يثبت اكتمال الحزمة واتساقها.
- **ثمانية عشر قالبًا وأربعة مسارات متكاملة وإطاران**، كل منها بالعربية والإنجليزية ببنية متطابقة.
- **باني النموذج المالي** الذي يحوّل ملف افتراضات قصيرًا إلى نموذج لـ36 شهرًا بمعادلات Excel حية وفحوص معقولية.

كل شيء مكتوب بصيغ Markdown و JSON و Python بأقل اعتماديات. استخدم ملفًا واحدًا أو الكل.

كل مهارة مكتفية بذاتها: يحمل مجلدها قوالبها باللغتين، ومسردًا عربيًا إنجليزيًا مشتركًا، وأي برنامج تحتاجه. وتجيب المهارات باللغة التي يكتب بها المستخدم.

وتلتزم المهارات كلها بالقواعد نفسها: لا أرقام ولا عملاء ولا حقائق سوقية مختلقة؛ لكل رقم مصدر وإلا صُرّح بأنه افتراض؛ وكل ما يخاطب شخصًا حقيقيًا أو ينفق مالًا أو لا رجعة فيه يُجهَّز ليعتمده إنسان؛ والمسائل القانونية والضريبية والاستثمارية تُشرح ثم تُحال إلى مختص.

## التثبيت

**Claude Code (إضافة تضم المهارات التسع)**

```
/plugin marketplace add malenezi/riyada
/plugin install riyada@riyada
```

**Claude Code (مهارة واحدة)**

```bash
git clone https://github.com/malenezi/riyada
cp -r riyada/skills/founder-context ~/.claude/skills/     # للاستخدام الشخصي
cp -r riyada/skills/founder-context .claude/skills/       # أو لمشروع بعينه
```

**تطبيقات Claude (الويب وسطح المكتب والجوال)**

شغّل `python tools/build_dist.py` ثم ارفع الملف المضغوط الذي تريده من `dist/` مهارةً مخصصة من إعدادات Claude. يحتاج البرنامجان تفعيل تنفيذ الأكواد، أما الإرشادات والقوالب فتعمل بدونه.

**وكلاء آخرون**

تتبع المهارات صيغة Agent Skills المفتوحة، فيستطيع استخدامها أي وكيل يقرأ مجلدات `SKILL.md`. والقوالب وملفات السياق ملفات Markdown عادية تعمل مع أي نموذج.

**بلا وكيل**

انسخ ما تحتاجه من [`templates/`](templates/) و[`context/`](context/) واملأه يدويًا.

المتطلبات: Python 3.9 أو أحدث للبرامج. ويحتاج ملف Excel مكتبة `openpyxl`، وبدونها يكتب باني النموذج الملخص وملف CSV.

## الاستخدام

اطلب ما تريد فحسب، ويحمّل Claude المهارة المناسبة من نص الطلب.

**1. اختبار فكرة**

> عملت عشر سنوات في مشتريات المستشفيات. اقترح ثلاث فرص تجارية وقيّمها وأخبرني بما أختبره أولًا.

يكتب Claude كل فرصة بصيغة: عميل + مشكلة + لماذا الآن، ويقيّمها على مقياس أدلة يكون فيه المجهول بدرجة 1، ويسمّي أخطر افتراض، ويكتب بطاقة تجربة بقاعدة قرار.

**2. بناء النموذج المالي**

> ابنِ نموذجًا ماليًا لـ36 شهرًا: 8 عملاء جدد في الشهر الأول بنمو 7% شهريًا، وتسرب 2.5%، و450 ريالًا شهريًا لكل عميل، وهامش 78%، وكلفة استحواذ 1800 ريال.

يملأ Claude ملف الافتراضات ويشغّل `build_model.py` ويعرض اقتصاديات الوحدة وشهر التعادل وأدنى رصيد نقدي. وإذا نفد النقد صرّح البرنامج بذلك وأعاد رمز خطأ. مُخرَج المثال التطبيقي: [model.ar.md](examples/mawja/model.ar.md).

**3. تجهيز الوكلاء كما ينبغي**

> نحن مؤسسان نشغّل شركة ناشئة لطلبات المقاهي. جهّز سياقنا حتى تتوقف الوكلاء عن الإجابات العامة.

يسأل Claude عن الطبقات السبع، ويكتب الحزمة وملف `CLAUDE.md`، ويشغّل الفاحص حتى تخلو من الأخطاء. نتيجة المثال التطبيقي: [examples/mawja/context/ar](examples/mawja/context/ar/).

**4. حوكمة وكيل**

> جهّز لنا مصفوفة اعتماد لوكيل خدمة العملاء: ما الذي ينفذه منفردًا وما الذي يحتاج موافقة؟

يصنّف Claude كل إجراء بحسب قابلية التراجع عنه وأثر الخطأ فيه، ويملأ [مصفوفة الاعتماد](templates/agents/approval-matrix.ar.md) بمستويات «نفّذ» و«اقترح» و«ممنوع»، ويحدد لكل حدٍّ وسيلة إنفاذه في النظام نفسه.

افحص الحزمة قبل أن تعتمد عليها الوكلاء:

```bash

```

ثلاث عشرة قاعدة: الطبقات الناقصة، والخانات غير المعبأة، والأقسام الفارغة، وتواريخ المراجعة المتقادمة، والملفات المفرطة الطول، وطبقة حوكمة بلا مصفوفة اعتماد أو بلا قاعدة منع، والحقل الواحد بقيمتين مختلفتين في ملفين، وخلايا الجداول الفارغة، والنصوص الشبيهة بالأسرار، وعلامات TODO المتروكة. التفاصيل: [lint-rules.md](skills/founder-context/references/lint-rules.md). ويعمل الفاحص على الحزم العربية والإنجليزية، ويعيد رمز خطأ عند وجود أخطاء، فيصلح بوابةً في التكامل المستمر.

## النموذج المالي

```bash
python shared/scripts/build_model.py examples/mawja/assumptions.json --out model --lang ar   # أو --lang en
```

يكتب `model.md` (الملخص السنوي واقتصاديات الوحدة والفحوص) و`model.csv` (الأرقام الشهرية) و`model.xlsx` (خمس أوراق؛ كل رقم شهري فيها معادلة تقودها ورقة الافتراضات، والنسخة العربية من اليمين إلى اليسار). وتُشغَّل تسعة فحوص في كل بناء، منها نفاد النقد (مانع)، والتسرب المرتفع أو الصفري، وضعف اقتصاديات الوحدة، وبطء الاسترداد، وهامش ربح يوحي بإغفال كلفة استخدام النماذج. البنية وطرق التكييف للخدمات والمنصات والمبيعات لمرة واحدة: [model-guide.md](skills/financial-modeling/references/model-guide.md).

## مثال تطبيقي

[`examples/mawja/`](examples/mawja/) شركة ناشئة افتراضية في الرياض، لها حزمة سياق مكتملة بالعربية والإنجليزية (تجتازان الفاحص دون أي ملاحظة) ونموذج مالي مبني باللغتين.

## كيف جرى التحقق

- يتحقق `tools/validate.py` من بيانات المهارات، ومن أن لكل ملف إنجليزي نظيرًا عربيًا بالعناوين وصفوف الجداول والخانات نفسها، ومن سلامة كل رابط نسبي، ومن صحة ملفات JSON.
- تغطي `tests/` الفاحص (الحزم السليمة، وكل قاعدة رئيسة، وعدم إظهار الأسرار) وباني النموذج (الأرقام المتوقعة للمثال، والمنع عند خطة غير ممولة، والتنبيهات، والتحقق من المدخلات، وبنية ملف Excel).
- أُعيد حساب معادلات ملف Excel في LibreOffice وقورنت بأرقام Python للأشهر الستة والثلاثين كلها باللغتين؛ وكان أكبر فرق 0.005، وهو تقريب ملف CSV.
- يشغّل التكامل المستمر ذلك كله على Python 3.9 و3.12.

ما لم يُنجَز بعد: لم تخضع المهارات لتقييمات منظمة مع مؤسسين حقيقيين في قطاعات متعددة.

## خريطة المستودع

```
skills/        تسع مهارات مكتفية بذاتها (SKILL.md, assets/, references/, scripts/)
context/       قوالب الطبقات السبع وقالب CLAUDE.md بنسختي .ar.md و .en.md
templates/     القوالب الأصلية بحسب المجال بنسختي .ar.md و .en.md
workflows/     أربعة مسارات متكاملة
frameworks/    إطار الكفايات وورقة الحصانة التنافسية
examples/      مثال تطبيقي: حزمة سياق ونموذج مالي
shared/        البرامج والمسرد التي تُنسخ إلى المهارات
tools/         sync_assets.py, validate.py, build_dist.py
tests/         اختبارات البرامج
```

عدّل الملفات في `templates/` و`context/` و`shared/` ثم شغّل `python tools/sync_assets.py` لتحديث النسخ داخل كل مهارة.

## حدود المستودع

يقدم هذا المستودع بنية ومنهجًا وفحوصًا. ولا يقدم استشارة قانونية أو ضريبية أو محاسبية أو استثمارية، ولا يعرف سوقك: فالأرقام والحقائق تأتي منك ومن مصادرك. وأنظمة تأسيس الشركات وأدوات التمويل وحماية البيانات والموافقة على الرسائل التسويقية والعمل تختلف من دولة إلى أخرى وتتغير؛ فتحقق منها لدى مستشار مؤهل في بلد نشاطك.
