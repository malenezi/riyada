# Security policy · سياسة الأمان

If you find a secret, real personal data, or a flaw in one of the scripts that could harm someone who runs it, please do not post the details publicly. Use GitHub's [private vulnerability reporting](https://github.com/malenezi/riyada/security/advisories/new) for this repository. If that page is not available, open an issue titled `security` that says only that you have a report, and the maintainer will arrange a private channel. This is a volunteer-maintained project; there is no guaranteed response time.
